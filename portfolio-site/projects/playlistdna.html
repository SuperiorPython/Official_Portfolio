PLAYLIST DNA

A Spotify playlist analytics dashboard that turns listening habits into clear, interactive insights.

Live Demo GitHub

Overview

Playlist DNA is an interactive Spotify playlist analyzer that maps a playlist’s identity across genre, artist patterns, time/era trends, and popularity—then presents the results in dedicated tabs designed for fast interpretation. It’s built to stay readable even for large playlists, turning raw Spotify data into insights you can actually use.

Key features

  • Overview snapshot: track count, unique artists, median popularity, and a “genre footprint” donut.
  • Evolution analytics: playlist growth over time + shifting genre footprint + weekday × hour add-pattern heatmap.
  • Genre & artist breakdowns: ranked charts with filtering and adjustable views for large playlists.
  • Time/era profiling: decade timeline + artist-by-year heatmap to reveal the playlist’s era identity.
  • Popularity analysis: distribution histogram + popularity vs. time to spot mainstream vs. niche trends.
  • Album cover wall: adjustable grid for visual browsing.
  • Track view: spotlight a selected track with stats + context (popularity, release year, playlist position).
  • Playlist Companion (AI): generates a narrative “vibe summary” and supports regeneration for different takes.
  • Export: save analysis output for reference.

How to use

  1. Open the app and authorize Spotify access.
  2. Select a playlist to analyze (public or your own).
  3. Start on Overview for instant stats + the genre footprint.
  4. Go to Evolution to see growth, how genres change, and when you add tracks (weekday × hour).
  5. Use Genres and Artists to identify what dominates the playlist.
  6. Use Time to explore decade trends and the artist-by-year heatmap.
  7. Use Popularity to understand distribution + changes over time.
  8. Use Covers to browse album art in a grid.
  9. Use Companion (AI) for a written vibe summary, then regenerate for a different angle.
  10. Use Export to save results.

Tech stack

Python Streamlit Spotify Web API OAuth Pandas Altair / Plotly Caching

What I learned

  • Implementing OAuth flows and handling auth edge-cases cleanly
  • Working around API limits with efficient request + caching patterns
  • Designing dashboards that prioritize readability over “data dumps”
  • Building resilient flows with fallbacks for missing or inconsistent API data
  • Structuring multi-tab UX so large datasets still feel navigable

Design highlights

  • Tab-based layout: keeps each insight focused and easy to scan.
  • Scales to large playlists: adjustable controls + chart views prevent clutter.
  • Insight-first visuals: trends, distributions, and composition patterns come first.
