PLAYLIST DNA

A Spotify playlist analytics dashboard that turns listening habits into clear, interactive insights.

Live Demo GitHub

Overview

Playlist DNA explores the “shape” of a playlist using Spotify data, surfacing trends through interactive visualizations and a clean UI built for fast interpretation.

Key features

  • Spotify API integration for playlist analysis
  • Interactive charts for audio features and distribution
  • Efficient request handling + caching for smoother performance
  • Responsive layout designed for data-heavy screens
